# ecommerce-website

A modern, responsive e-commerce web application featuring a sleek UI, interactive shopping cart, product catalog with dynamic filtering, and complete checkout experience.

## ✨ Features

- **Storefront & Navigation**: Modern responsive header, animated hero section, categories, and promotional banners.
- **Product Catalog (`products.html`)**: Real-time search, category filters (Electronics, Accessories, Footwear, Beauty), price sorting, and dynamic grid rendering.
- **Product Details (`product-detail.html`)**: Detailed image views, specs, ratings, and quantity selectors.
- **Shopping Cart (`cart.html`)**: Real-time cart state management, item count badges, quantity updates, and cost calculations.
- **Checkout Flow (`checkout.html`)**: Step-by-step checkout with address inputs, payment selection, order summaries, and validation.
- **Responsive & Animated**: Crafted with vanilla HTML, CSS, and JavaScript with custom micro-animations and mobile menu support.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally using a local development server:

```bash
# Using VS Code Live Server or Python http.server
python -m http.server 3000
```
